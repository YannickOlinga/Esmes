# ESMES Business School — React

Refonte du site ESMES Business School avec React, Vite et Lucide.

## Démarrer en local

```bash
npm install
npm run dev
```

## Vérifier la production

```bash
npm run build
npm run preview
```

## Structure

- `src/App.jsx` : sections de la page d’accueil et données de formations
- `src/styles.css` : identité visuelle bleu/blanc et responsive
- `index.html` : métadonnées et point d’entrée

## Direction artistique

Bleu profond `#123B70`, bleu `#2878C8`, bleu clair `#EAF3FC`, blanc. Images de démonstration chargées depuis Unsplash.

Les informations des formations sont une première reprise éditoriale de la page publique des formations. Avant mise en production, valider les intitulés, modalités, coordonnées, liens de candidature et mentions légales avec l’établissement.
